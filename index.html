Architecture & Verification Checklist (HW 2 Criteria)

  1. FIFO Concurrency Invariant: Click "Enqueue All 4". Notice all 4 tasks enter the queue simultaneously, but download and decode strictly sequentially (one at a time) via the isProcessing mutex guard.
  2. AbortController Token Cancellation: Click "Cancel Download" while a track is downloading. The active task immediately transitions to ABORTED status and the queue immediately proceeds to the next track without deadlock.
  3. Memory Safety (Zero Leaks): Observe Active Sources (never exceeds 1) and Sources Cleaned Up. Every time a song finishes or skips, AudioBufferSourceNode.disconnect() is explicitly called to allow garbage collection.
  4. 60fps Canvas Without State Thrashing: The visualizer runs in a decoupled requestAnimationFrame loop reading directly from analyser.getByteFrequencyData() without triggering DOM or React re-renders. Check the FPS: 60.0 counter.

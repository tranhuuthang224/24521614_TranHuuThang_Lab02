UIT Academic Records Management System with 2D Roving Tabindex, Real-time Filtering, Multi-column Sorting, and Zero Div-Soup.

Keyboard Navigation & Accessibility Guide (W3C APG Grid Pattern)

  1. ↑ ↓ ← → : 2D Cell Navigation — Seamlessly moves active focus between grid cells and column headers via Roving Tabindex.
  2. Home / End : Row Boundaries — Moves focus to first or last cell in active row (Ctrl+Home / Ctrl+End moves to very first or last cell in entire grid).
  3. PageUp / PageDown : Pagination — Navigates to previous or next page of student records.
  4. Space : Toggle — Toggles row selection checkbox on data rows, or toggles sort order on column headers.
  5. Enter : Activate — Triggers row selection and fires the onRowSelect callback with student payload.
  6. Tab / Shift+Tab : Grid Exit — Moves focus into or out of the grid component to adjacent interactive controls without keyboard trapping.
